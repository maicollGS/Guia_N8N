⚙️ Instalación

Hay tres formas de usar n8n. La más recomendada para producción es Docker. Para empezar rápido, usa npx.

Terminal
# Requiere Node.js 18+
# Instalar y ejecutar con npx
npx n8n

# Con datos persistentes en carpeta propia
npx n8n --tunnel

# Abre en el navegador
# → http://localhost:5678
Advertencia
npx no guarda datos permanentemente. Solo para pruebas rápidas.
Docker
# Ejecutar n8n con Docker
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v n8n_data:/home/node/.n8n \
  docker.n8n.io/n8nio/n8n

# Con variables de entorno
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -e N8N_BASIC_AUTH_ACTIVE=true \
  -e N8N_BASIC_AUTH_USER=admin \
  -e N8N_BASIC_AUTH_PASSWORD=miPassword123 \
  -v n8n_data:/home/node/.n8n \
  docker.n8n.io/n8nio/n8n
docker-compose.yml
version: '3.8'

services:
  n8n:
    image: docker.n8n.io/n8nio/n8n
    restart: always
    ports:
      - "5678:5678"
    environment:
      - N8N_BASIC_AUTH_ACTIVE=true
      - N8N_BASIC_AUTH_USER=admin
      - N8N_BASIC_AUTH_PASSWORD=password_seguro
      - GENERIC_TIMEZONE=America/Bogota
      - WEBHOOK_URL=https://tu-dominio.com/
    volumes:
      - n8n_data:/home/node/.n8n

volumes:
  n8n_data:
Terminal
# Levantar en segundo plano
docker-compose up -d

# Ver logs
docker-compose logs -f n8n

# Detener
docker-compose down

🖥️ Interfaz de n8n

La interfaz de n8n es un canvas visual donde arrastras y conectas nodos. Cada nodo hace una tarea específica y los datos fluyen entre ellos como JSON.

🖼️
Canvas
El área principal donde construyes workflows. Arrastra nodos, conéctalos y ejecuta. Zoom, pan y atajos de teclado.
📦
Panel de nodos
Buscador de todos los nodos disponibles. Busca por nombre o categoría. Presiona Tab para abrirlo.
⚙️
Panel de configuración
Al hacer clic en un nodo, se abre su configuración a la derecha. Aquí defines parámetros, expresiones y credenciales.
📊
Historial de ejecuciones
Cada vez que el workflow corre, se guarda el resultado. Puedes ver input/output de cada nodo para depurar.
🔑
Credenciales
Sección para guardar tokens, API keys y contraseñas de forma encriptada. Se reutilizan en múltiples workflows.
📋
Templates
Biblioteca de workflows prehechos. Importa directamente y personaliza. Cubre los casos más comunes.
Flujo de datos
Los datos fluyen como objetos JSON entre nodos. Cada nodo recibe items[] — un array donde cada elemento tiene json con los datos y binary para archivos. Puedes acceder a ellos con expresiones {{ $json.campo }}.
📐 Tipos de conexión
➡️
Main (datos)
Conexión estándar entre nodos. Pasa el array de items de un nodo al siguiente.
🤖
AI connections
Conexiones especiales para LLMs, memoria y herramientas en nodos de IA (color distinto).
⚠️
Error path
Ruta alternativa cuando un nodo falla. Permite manejar errores con gracia sin detener todo el workflow.

⚡ Triggers — Cómo inicia un workflow

Todo workflow empieza con un trigger. Es el primer nodo y define cuándo y cómo se ejecuta la automatización.

🕐
Schedule Trigger (Cron)
Ejecuta el workflow en intervalos regulares — cada hora, diariamente, semanalmente o con expresión cron personalizada.
# Expresiones Cron más comunes
0 9 * * 1-5    # Lunes a viernes a las 9am
0 * * * *      # Cada hora
*/15 * * * *   # Cada 15 minutos
0 0 * * 0      # Domingos a medianoche
🪝
Webhook Trigger
Recibe peticiones HTTP externas. Apps envían datos a n8n mediante POST. Ideal para integraciones en tiempo real.
# URL generada automáticamente
https://tu-n8n.com/webhook/UUID

# Soporta: GET, POST, PUT, DELETE
# Auth: Header, Basic, JWT
📧
Email Trigger (IMAP/Gmail)
Monitorea una bandeja de entrada. Se dispara cuando llega un correo nuevo que coincide con un filtro.
🖱️
Manual Trigger
Se ejecuta manualmente haciendo clic en "Execute Workflow". Ideal para pruebas y workflows bajo demanda.
💬
Chat Trigger
Abre una interfaz de chat integrada. Perfecto para agentes de IA conversacionales. Embebible en sitios web.
📝
Form Trigger
Genera un formulario web automáticamente. Cuando alguien lo envía, inicia el workflow con los datos del formulario.
Tip de producción
Para webhooks en producción, activa siempre "HTTPS" y configura autenticación (Header Auth o Basic Auth). Nunca dejes un webhook público sin protección.
🔄 Activar / Desactivar workflows
1
Toggle en la esquina superior derecha
El switch de activación controla si el workflow responde a triggers automáticos. Los workflows inactivos no se ejecutan.
2
Estado activo (verde)
El workflow monitorea su trigger. Los Schedule Triggers comienzan a correr según el horario definido.
3
Estado inactivo (gris)
Solo puedes ejecutarlo manualmente. Los webhooks no responden hasta reactivarlo.
✨ Expresiones — El poder de n8n

Las expresiones permiten acceder dinámicamente a los datos del workflow. Se escriben con doble llave {{ }} y usan JavaScript dentro.

Variables del contexto
Expresiones disponibles
{{ $json }}
El objeto JSON del item actual. Raíz de todos los datos del nodo anterior.
{{ $json.campo }}
Accede a un campo específico del item. Ej: {{ $json.email }}
{{ $json.objeto.sub }}
Accede a propiedades anidadas. Ej: {{ $json.user.name }}
{{ $node["Nombre"].json }}
Accede a datos de un nodo específico por su nombre.
{{ $items("Nodo")[0].json }}
Primer item de la salida de un nodo específico.
{{ $env.MI_VARIABLE }}
Variable de entorno configurada en el servidor.
{{ $now }}
Fecha y hora actual como objeto Luxon.
{{ $today }}
Fecha de hoy (inicio del día).
{{ $runIndex }}
Índice de la iteración actual en un loop.
{{ $workflow.name }}
Nombre del workflow actual.
Ejemplos prácticos
Expresiones n8n
// Texto con datos dinámicos
"Hola {{ $json.nombre }}, tu pedido #{{ $json.id }} está listo."

// Fecha formateada (Luxon)
{{ $now.toFormat('dd/MM/yyyy HH:mm') }}

// Fecha de hace 7 días
{{ $now.minus({ days: 7 }).toISODate() }}

// Condicional en línea
{{ $json.activo ? 'Activo' : 'Inactivo' }}

// Transformar a mayúsculas
{{ $json.nombre.toUpperCase() }}

// Primer elemento de un array
{{ $json.tags[0] }}

// Longitud de un array
{{ $json.items.length }}

// Acceso a nodo anterior específico
{{ $node["HTTP Request"].json.data.id }}

// Parsear número
{{ parseInt($json.precio) * 1.19 }}

// Formatear moneda
{{ new Intl.NumberFormat('es-CO', {style:'currency', currency:'COP'})
   .format($json.valor) }}
Nodo Code — JavaScript completo
Code Node — JavaScript
// Procesa TODOS los items a la vez
// Modo "Run Once for All Items"
const items = $input.all();

const resultado = items.map(item => {
  const data = item.json;

  return {
    json: {
      id:       data.id,
      nombre:   data.first_name + ' ' + data.last_name,
      email:    data.email.toLowerCase(),
      esVip:    data.compras > 10,
      procesado: new Date().toISOString()
    }
  };
});

return resultado;

🔀 Lógica y Control de Flujo

n8n ofrece nodos completos para construir lógica compleja: condicionales, bucles, división de datos y transformaciones.

🔀
IF Node
Divide el flujo en dos rutas según una condición booleana.
Condición: {{ $json.valor > 100 }}
→ True:  procesar como premium
→ False: procesar como estándar
🔢
Switch Node
Múltiples rutas según el valor de un campo. Como un switch/case en código.
Campo: $json.estado
→ "nuevo":    enviar bienvenida
→ "activo":   procesar pedido
→ "inactivo": enviar reactivación
🔄
Loop Over Items
Itera sobre cada item del array. Útil cuando necesitas hacer algo diferente por cada elemento.
🔗
Merge Node
Combina dos flujos en uno. Modos: Append, Merge by Key, Combine, Wait.
✂️
Split Out
Convierte un array dentro de un item en múltiples items individuales para procesarlos uno a uno.
📊
Aggregate
Agrupa y resume datos. Calcula totales, promedios, conteos de múltiples items en uno.
Sub-workflows
Puedes llamar un workflow desde otro con el nodo Execute Workflow. Esto permite crear workflows reutilizables — como funciones en programación. El workflow hijo recibe datos y devuelve resultados al padre.
🌐 HTTP Request — Conecta cualquier API

El nodo HTTP Request es el más poderoso de n8n. Si una app tiene API REST, puedes conectarla aunque no tenga nodo dedicado.

Método:  GET
URL:     https://api.ejemplo.com/v1/users
Headers:
  Authorization: Bearer {{ $env.API_TOKEN }}
  Content-Type:  application/json

// Petición POST con body dinámico
Método:  POST
URL:     https://api.crm.com/contacts
Body (JSON):
{
  "email":  "{{ $json.email }}",

// Manejo de paginación

🛡️ Manejo de Errores

Un workflow robusto maneja fallos con gracia. n8n ofrece varias estrategias para gestionar errores sin detener toda la automatización.

1
Error Output — Ruta de error por nodo
Cada nodo tiene una salida de error (margen rojo). Conecta un nodo a esa salida para manejar el fallo sin detener el workflow. El nodo siguiente recibe el error como $json.error.
2
Error Trigger — Workflow de manejo global
Crea un workflow dedicado a errores con el nodo Error Trigger. Este workflow se activa automáticamente cuando cualquier workflow del sistema falla. Úsalo para enviar alertas a Slack o email.
3
Try/Catch en el nodo Code
En el nodo Code, usa try/catch para capturar errores de JavaScript y decidir qué hacer sin lanzar el error al workflow.
4
Reintentos automáticos
En la configuración de cualquier nodo → "Settings" → "On Error" → "Retry on Fail". Define el número de reintentos y el intervalo entre ellos. Ideal para APIs con rate limiting.
Workflow de Error Global
// Datos disponibles en el Error Trigger
{
  "workflow": {
    "id":   "id-del-workflow",
    "name": "Nombre del workflow"
  },
  "node": {
    "name": "Nombre del nodo que falló",
    "type": "n8n-nodes-base.httpRequest"
  },
  "error": {
    "message": "Error message",
    "stack":   "Stack trace..."
  },
  "execution": {
    "id":  "execution-id",
    "url": "https://n8n.tu-dominio.com/execution/id"
  }
}
Buena práctica
Configura siempre un workflow de error global que envíe una notificación a Slack o email cuando falla cualquier automatización. Incluye el link directo a la ejecución fallida para debuggear rápidamente.
💡 Casos de uso reales 2025

Estos son los workflows más populares y útiles construidos con n8n en entornos de producción.

📊
Reporte automatizado de datos
Genera reportes diarios/semanales consultando bases de datos, procesando con código y enviando por email o Slack.
Schedule (9am) → Postgres Query → Code (transformar) → Google Sheets (guardar) → Gmail (enviar PDF)
🤖
Agente de soporte IA con base de conocimiento
Chatbot que responde preguntas consultando documentación interna, crea tickets y escala a humano cuando no puede responder.
Chat Trigger → AI Agent (GPT-4) → Tool: buscar docs → Tool: crear ticket → Respuesta
💼
Pipeline de leads con IA
Cuando llega un nuevo lead, IA analiza su empresa, lo clasifica por tamaño, lo agrega al CRM y notifica al vendedor correcto.
Webhook (Formulario) → OpenAI (analizar) → IF (clasificar) → HubSpot (crear) → Slack (notificar)
📱
Monitoreo de redes sociales
Monitorea menciones de tu marca, analiza el sentimiento con IA y alerta al equipo cuando detecta comentarios negativos.
Schedule (cada hora) → HTTP (buscar menciones) → OpenAI (sentimiento) → IF (negativo) → Slack (alerta)
🏥
Sincronización de datos HIPAA/GDPR
Sincroniza datos sensibles entre sistemas internos sin que salgan de tu infraestructura. Logs de auditoría automáticos.
Webhook interno → Validar datos → Postgres (guardar) → Log auditoría → Notificación interna
📧
Email marketing automatizado
Secuencia de onboarding automática. Bienvenida, tutoriales y seguimientos personalizados según el comportamiento del usuario.
Webhook (registro) → Día 0: bienvenida → Wait 3 días → Día 3: tutorial → Wait 7 días → Seguimiento
